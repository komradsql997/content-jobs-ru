# Текст и дело — вакансии для специалистов по контенту

Бесплатный MVP агрегатора **российских вакансий для работы в РФ**. Редакторы, UX-писатели, копирайтеры, технические писатели, главреды, контент-маркетологи.

**Статус:** ранний MVP. Источники из `sources.json` пока кандидаты на интеграцию, а не гарантированно работающие парсеры. Реальная загрузка должна быть подтверждена отчётом GitHub Actions. Не подменять нулевые результаты фиктивными вакансиями.

## Как устроено
- `site/` — статический сайт без сервера и платных сервисов, получает `jobs.json`.
- `scripts/collect.py` — проверяет российские карьерные площадки, извлекает карточки, фильтрует по профессиям и географии, удаляет повторы и выставляет балл полноты описания.
- `sources.json` — список сайтов. Внесение нового источника не требует изменения кода.
- `.github/workflows/update.yml` — запуск в 11:00, 16:00 и 21:00 МСК, сохранение отчёта, обновление сайта и попытка деплоя GitHub Pages.
- `reports/source_diagnostics.json` — отчёт проверки источников; в Actions он также прикрепляется как артефакт.

Telegram-каналы пока НЕ подключены. Для законного сбора потребуются согласование с владельцами и подключение бота к каналам. Не используем международные агрегаторы и hh API.

## Бесплатное размещение
1. GitHub → репозиторий → **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Actions → **Обновить вакансии и сайт** → **Run workflow**. При первом запуске потребуется разрешить Actions в репозитории.
3. После успешного запуска вкладка **Settings → Pages** покажет адрес сайта. Обычно это `https://komradsql997.github.io/content-jobs-ru/`.
4. Отчёт смотри в Actions → последний запуск → **source-diagnostics**. Пока источники не дали вакансии, сайт покажет честное пустое состояние.

## Локальная проверка (необязательно)
```bash
pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/collect.py
python -m http.server 8000 --directory site
```

Сборщик не обходит блокировки, не отключает проверку сертификатов, не использует платные API. Публикуется только короткая выдержка и ссылка на первоисточник. Права и условия каждого источника нужно проверять до постоянной публичной эксплуатации. Даты у объявлений без исходной даты — время обнаружения, а не публикации.
