# Главред проверил вакансию

Бесплатный публичный MVP: только вакансии контент-специалистов российских компаний и вакансии для работы из РФ.

**Действующий сайт:** https://komradsql997.github.io/content-jobs-ru/

## Источники — две категории

- **100 карьерных сайтов российских работодателей.** Список `source_catalog.json`. Автоматический обход в `scripts/collect.py`, диагностика каждого адреса в `reports/source_diagnostics.json` и `reports/source_catalog_health.json`. Добавление адреса ≠ подтверждённое извлечение вакансий: смотрим поле `saved` в отчёте.
- **45 публичных Telegram-каналов.** Список в том же каталоге; `scripts/telegram_public.py` читает открытые страницы `t.me/s/<channel>` без авторизации, прокси и админских прав. В ленту попадают короткие сведения с прямой ссылкой на оригинальный пост. Диагностика: `reports/telegram_public_diagnostics.json`. Извлечение зависит от доступности публичной страницы и может прекратиться в любой момент.

**Предупреждение о Telegram.** Технический доступ к открытым публикациям не означает наличия прав на их регулярное автоматическое агрегирование. У Telegram есть ограничения на использование контента и автоматизированный сбор; перед устойчивым публичным распространением необходимо прояснить применимые условия и права на данные. Не перепубликовать полный текст постов и не обходить ограничения платформы.

## Обновление и бюджет

GitHub Actions запускает оба сборщика в **11:00, 16:00 и 21:00 МСК**. Он обновляет `site/jobs.json` и архив коротких Telegram-карточек в `data/telegram_public_jobs.json`, после чего GitHub Pages публикует сайт. Плановый запуск может задерживаться. Поиск и фильтры работают локально в браузере.

**Платных API и подписок нет; бюджет на источники — 0 ₽/месяц.**

## Данные и контроль качества

- Кандидат допускается только при найденной специализации и явных признаках, что работа в России.
- Объявления старше 14 суток в Telegram удаляются. Дата берётся из публикации.
- Резюме кандидатов, подборки из нескольких вакансий, объявления других профессий и заведомо закрытые позиции должны исключаться. Автоматический фильтр не идеален; нужна выборочная проверка.
- Зарплата отображается только если явно указана в объявлении. Ориентир рассчитывается лишь при наличии не менее трёх вакансий с фактическими зарплатами в близкой категории и уровне; иначе скрыт.
- Информативность 0–100 — оценка **полноты текста**, не качества компании.
- Если вакансия встречается из нескольких источников, попытка дедупликации объединяет совпадения и сохраняет ссылки на источники.
- Подробный HTML или полный пост Telegram не публикуем, даём краткое описание и прямой URL первоисточника.

## Запуск/проверки

GitHub → Actions → «Обновить вакансии и сайт» → Run workflow. Результат проверяем в Actions и публичном `site/jobs.json`. В артефакте `source-diagnostics` — отчёты всех источников.

Локально, если необходимо:

```bash
pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/collect.py
python scripts/telegram_public.py
```

Важное ограничение: GitHub Pages — статический хостинг, а не место для постоянной работы сервера. Для MVP с обновлениями три раза в день этого достаточно.
